# PlayRoom

A real-time browser party-game site for people playing together in the same room.

## Included
- Name-only entry
- Create/Join rooms with 6-character codes
- Host controls
- Real-time player list
- Who Is The Imposter? with Food, Animals, Objects and Places
- Placeholder game cards for the planned party-game lineup
- English UI
- Mobile-friendly layout for iPhone, Android and desktop
- WebSocket backend

## Run locally
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:10000`

## Deploy
Recommended: Render Web Service.
Build Command: `npm install`
Start Command: `npm start`
The service must be a Web Service (not Static Site) because rooms use WebSockets.

See the deployment notes in the chat that came with this ZIP.
